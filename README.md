# RIS 360 – แอปแบบประเมิน 360 องศา ฝ่ายขายรถเล็ก

แอปบนมือถือแบบ PWA กดติดตั้งลงหน้าจอหลักได้ทั้ง iPhone และ Android
- **ตัวแอป** (โฟลเดอร์นี้) เผยแพร่ฟรีผ่าน GitHub Pages
- **ข้อมูล** (รายชื่อ คู่ประเมิน คำตอบ) เก็บใน Google Sheet ของ HR โดยมี Apps Script ทำหน้าที่เป็น API

```
มือถือผู้ประเมิน ──► แอป (GitHub Pages) ──► Apps Script API ──► Google Sheet ของ HR
```

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด (หน้าผู้ประเมิน, Dashboard HR, รายงานรายบุคคล) |
| `config.js` | **ต้องแก้** – ใส่ URL ของ Apps Script API |
| `manifest.webmanifest`, `sw.js`, `icons/` | ทำให้ติดตั้งเป็นแอปได้ |
| `apps-script/Code.gs` | โค้ดฝั่งเซิร์ฟเวอร์ – นำไปวางใน Apps Script ของ Google Sheet (ไม่ได้รันบน GitHub) |
| `apps-script/appsscript.json` | ค่าตั้งของ Apps Script (ไม่บังคับ) |

> ⚠️ **ห้ามอัปโหลดไฟล์ Excel รายชื่อพนักงานขึ้น GitHub**
> GitHub Pages แบบฟรีต้องใช้ repo สาธารณะ (ใครก็เปิดดูได้) ไฟล์ข้อมูลอยู่ใน Google Drive ของ HR เท่านั้น

## ขั้นที่ 1 – ตั้งค่า Google Sheet + API (ประมาณ 10 นาที)

1. อัปโหลด `RIS_360_Sales_LCV_2569.xlsx` ขึ้น Google Drive ของ HR แล้วเปิดด้วย Google Sheets
   (ไฟล์ > บันทึกเป็น Google ชีต)
2. ตรวจชีต **พนักงาน** และ **คู่ประเมิน** แล้วเปลี่ยน **รหัสผ่าน HR** ในชีต **ตั้งค่า**
3. ในชีตนั้นไปที่เมนู **ส่วนขยาย > Apps Script** ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดจาก `apps-script/Code.gs` จากนั้นกดบันทึก 💾
4. กด **ทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้รายการใหม่**
   - ประเภท: **เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
   - กด **ทำให้ใช้งานได้** แล้ว **อนุญาตสิทธิ์** ด้วยบัญชี HR
     (ถ้า Google เตือน "แอปยังไม่ได้รับการยืนยัน" ให้กด ขั้นสูง > ไปที่ … (ไม่ปลอดภัย) เพราะเป็นโค้ดของเราเอง)
5. คัดลอก **URL ของเว็บแอป** ที่ลงท้ายด้วย `/exec`
   ถ้าเปิด URL นี้ใน browser แล้วเห็น `{"ok":true,"service":"RIS 360 API",...}` แสดงว่า API ใช้งานได้

## ขั้นที่ 2 – ใส่ URL ในแอป

เปิดไฟล์ `config.js` แล้วแทนที่ข้อความ `วาง_ID_ของคุณที่นี่` ด้วย URL จากข้อ 5 เช่น

```js
window.RIS360_CONFIG = {
  API_URL: 'https://script.google.com/macros/s/AKfycb...ยาวๆ.../exec'
};
```

## ขั้นที่ 3 – อัปโหลดขึ้น GitHub (ผ่านหน้าเว็บ ไม่ต้องลงโปรแกรม)

1. เข้า github.com แล้วกด **New repository**
   - ชื่อ: `ris-360` (ใช้ชื่ออื่นก็ได้)
   - เลือก **Public** (GitHub Pages แบบฟรีต้องเป็น Public)
   - กด **Create repository**
2. ในหน้า repo กด **uploading an existing file** (หรือ Add file > Upload files)
   แล้วลาก**ไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์นี้**มาวาง (`index.html`, `config.js`, `icons/` …)
   จากนั้นกด **Commit changes**
3. ไปที่ **Settings > Pages**
   - Source: **Deploy from a branch**
   - Branch: **main**, โฟลเดอร์ **/ (root)** แล้วกด **Save**
4. รอ 1–2 นาที จะได้ลิงก์แอปรูปแบบ `https://ชื่อบัญชี.github.io/ris-360/`

## ขั้นที่ 4 – ทดสอบและเปิดใช้

1. เปิดลิงก์แอปบนมือถือ แล้วทดลองล็อกอินด้วยรหัสพนักงานจริง 2–3 คน
2. ลองเข้า **สำหรับ HR** ด้วยรหัสผ่าน HR
3. ลบแถวทดสอบในชีต **คำตอบ** แล้วเปลี่ยน **โหมดทดสอบ** เป็น `N`
   (เมื่อปิดโหมดทดสอบ แอปจะส่งคำตอบได้เฉพาะช่วงวันเปิด–ปิดเท่านั้น)
4. ส่งลิงก์แอปเข้า LINE หรือทำเป็น QR Code สำหรับวันชี้แจง

**ติดตั้งลงมือถือ**
- iPhone: เปิดใน **Safari** แล้วกดปุ่มแชร์ > **เพิ่มไปยังหน้าจอโฮม**
- Android: เปิดใน **Chrome** แล้วกดปุ่ม **ติดตั้งแอป** ในหน้าแรก หรือเมนู ⋮ > **ติดตั้งแอป**

## การแก้ไขภายหลัง

| ต้องการแก้ | ทำอย่างไร |
|---|---|
| รายชื่อ, คู่ประเมิน, วันเปิด-ปิด, น้ำหนักคะแนน | แก้ใน Google Sheet ได้ทันที ไม่ต้องแก้โค้ด |
| หน้าตาแอป (`index.html`) | แก้ไฟล์บน GitHub (กดรูปดินสอ) แล้วเปลี่ยน `ris360-v1` ใน `sw.js` เป็น `ris360-v2` เพื่อให้มือถือโหลดไฟล์ใหม่ |
| โค้ดฝั่งเซิร์ฟเวอร์ (`Code.gs`) | แก้ใน Apps Script แล้วไปที่ Deploy > **จัดการการทำให้ใช้งานได้** > ✏️ > เวอร์ชัน: **เวอร์ชันใหม่** (URL เดิมยังใช้ได้) |

## ความปลอดภัย

- ทั้งลิงก์แอปและ API เป็นลิงก์สาธารณะ ระบบยืนยันตัวตนผู้ประเมินด้วยรหัสพนักงาน
  ถ้าต้องการกันคนกรอกรหัสพนักงานของคนอื่น ให้ตั้ง **ใช้ PIN = Y** ในชีตตั้งค่า แล้วแจก PIN ในชีตพนักงานให้แต่ละคนแบบส่วนตัว
- รายงานแสดงคะแนนเป็นค่าเฉลี่ยรายกลุ่ม ส่วนความเห็นไม่ระบุชื่อผู้ตอบ
  แต่ในชีต **คำตอบ** ยังมีรหัสผู้ประเมินอยู่ จึงควรจำกัดสิทธิ์เปิดชีตไว้เฉพาะ HR
